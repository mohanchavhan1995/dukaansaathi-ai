DukaanSaathi AI - मोफत Prototype v1

यामध्ये:
- मराठी / हिंदी / इंग्रजी भाषा
- ग्राहक उधारी नोंद आणि पूर्ण झालेली उधारी काढणे
- स्टॉक नोंद आणि कमी स्टॉक सूचना
- रोजची विक्री व खर्च; साधा नफा अंदाज
- जाहिरात मजकूर टेम्पलेट
- CSV डेटा डाउनलोड
- PWA install आणि offline cache (पहिल्या online load नंतर)

महत्त्वाच्या मर्यादा:
1. डेटा फक्त त्या ब्राउझर/डिव्हाइसवर सेव्ह होतो. दुसऱ्या फोनवर दिसणार नाही.
2. हा prototype आहे; सुरक्षित cloud login, multi-user accounts, online payment, वास्तविक AI API जोडलेले नाहीत.
3. नफा हा विक्री - नोंदवलेला खर्च असा साधा अंदाज आहे; अकाउंटिंग/कर सल्ला नाही.
4. ग्राहकांची वैयक्तिक माहिती संवेदनशीलपणे हाताळा. सार्वजनिक/शेअर्ड संगणकावर वापरू नका.

मोफत वेबसाइटवर प्रकाशित करण्यासाठी:
A. GitHub.com वर मोफत खाते तयार/लॉगिन करा.
B. New repository निवडा. नाव: dukaansaathi-ai
C. Public निवडा आणि Create repository करा.
D. Add file > Upload files निवडा.
E. या ZIP मधील सर्व फाईल्स unzip करून थेट repository मध्ये upload करा (फोल्डरच्या आत नव्हे; index.html root मध्ये असावी).
F. Commit changes करा.
G. Repository Settings > Pages उघडा.
H. Build and deployment मध्ये Deploy from a branch निवडा.
I. Branch: main आणि folder: /(root) निवडा, Save करा.
J. काही मिनिटांनी Pages मध्ये दिलेली वेबसाइट लिंक उघडा.

मोबाइलवर App सारखी install:
- वेबसाइट Chrome मध्ये उघडा.
- तीन डॉट्स > Add to Home screen / Install app निवडा.
- Add / Install करा.

पहिल्या ग्राहकांसाठी:
- आधी 3-5 दुकानदारांना prototype दाखवा.
- त्यांच्या परवानगीने dummy data टाकून वापरून पहा.
- पैसे घेण्यापूर्वी cloud backup/login आणि privacy यांची गरज स्पष्ट करा.
